## En bref

Les quatre supports qui valent le détour sur git, du manuel au jeu. Rien ici
n'est de moi : cette fiche ne contient que des pointeurs.

## Lire

- **[Pro Git, en français](https://git-scm.com/book/fr/v2)** — le livre de
  référence, gratuit et complet. C'est celui à ouvrir quand une notion résiste :
  les chapitres sur les branches et sur les objets internes expliquent *pourquoi*
  git se comporte comme il le fait, ce qu'aucun aide-mémoire ne fait.

## Voir

- **[Visualizing Git](https://git-school.github.io/visualizing-git/)** — tu tapes
  une commande, le graphe des commits bouge devant toi. Le plus rapide pour
  comprendre ce que `rebase` fait réellement par rapport à `merge`.

## Pratiquer

- **[Learn Git Branching](https://learngitbranching.js.org/?locale=fr_FR)** —
  exercices progressifs, en français. Le meilleur rapport temps passé / notions
  acquises sur les branches, `rebase` et `cherry-pick`.
- **[Oh My Git!](https://ohmygit.org/)** — un vrai jeu de cartes sur un dépôt
  réel. Plus lent que les précédents, mais il installe des réflexes.

## Dans quel ordre

Learn Git Branching pour dégrossir, Visualizing Git quand une commande précise
te surprend, Pro Git quand tu veux comprendre le modèle sous-jacent plutôt que
mémoriser des recettes.
